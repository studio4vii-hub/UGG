# Telegram Mini App и GitHub Pages

Подготовлено 5 ноября 2026. Публикация и привязка к боту пока не выполнены: владелец готовит данные целевого GitHub-аккаунта. Username бота также нужен для завершения.

## Что готово
- Приложение загружает официальный Telegram Web Apps SDK. В браузере работает обычный режим.
- В Telegram вызываются ready/expand, используются безопасные отступы и нативная кнопка «Назад» для страниц и окон. Платежи и авторизация этим не подключаются.
- Никакие токены, initData, заказы или контакты не отправляются на GitHub или сторонний сервер. Запрос пока сохраняется локально.
- Добавлен SVG из ссылки в присланной владельцем странице Википедии: images/brand/ugg-logo.svg. Источник: https://upload.wikimedia.org/wikipedia/commons/6/6e/UGG_Australia_logo.svg. Этот источник не объявляется официальным размещением UGG.
- .github/workflows/pages.yml готовит public/ и публикует сайт через GitHub Pages при обновлении main. В репозитории содержимое этой папки должно находиться в корне.
- prepare-pages.mjs копирует только необходимые файлы сайта и assets; служебные черновики, документы и локальные пользовательские данные не входят в public/.
- preview.html остается автономным, без сетевого подключения SDK; логотип и фотографии встроены.

## Завершение после получения аккаунта
1. Создать или выбрать репозиторий на указанном владельцем GitHub-аккаунте. Доступ подтвердить через GitHub, без токенов в чате.
2. Загрузить исходники из этой папки в корень main. В Settings → Pages выбрать Source: GitHub Actions и дождаться успешного workflow.
3. Проверить полученный HTTPS-адрес, изображения, каталог, корзину и загрузку без ошибок. Относительные пути поддерживают адрес project Pages вида https://ACCOUNT.github.io/REPOSITORY/.
4. В @BotFather выбрать нужного бота → Bot Settings → Menu Button → Configure menu button, задать надпись «Магазин» и HTTPS-адрес. Для Main Mini App настроить URL в настройках Mini App бота. Нельзя использовать localhost4300 как адрес для посетителей Telegram.
5. Открыть приложение из меню бота в мобильном и desktop Telegram и проверить кнопку «Назад», клавиатуру/отступы, выбор вариантов и корзину. Пока проверено только в обычном браузере и с тестовым SDK; реальная проверка Telegram ожидает публикации и бота.

Не помещать токен BotFather в HTML/JS, репозиторий или GitHub Pages. Если позднее появится серверная отправка заявок, токен и проверка initData должны находиться на сервере.

Официальные инструкции: https://core.telegram.org/bots/webapps и https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages .
