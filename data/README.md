# Товарная матрица и фид

Создано 5 ноября 2026 года. CSV в UTF-8 с BOM, разделитель — запятая, поля в кавычках. В Excel при необходимости выберите «Данные → Из текста/CSV», кодировка UTF-8, разделитель «запятая». SKU и артикулы импортируйте как текст.

## Файлы

- `catalog-matrix.csv` — основная рабочая матрица: 8 моделей × 3 тестовых цвета × 6 тестовых размеров = 144 варианта. SKU внутренние, с префиксом UGGD, и не являются артикулами UGG. Сочетания модели, размера и цвета пока не проверены.
- `field-dictionary.csv` — назначение всех 26 полей.
- `competitor-observations.csv` — отдельная таблица для наблюдений за конкурентами. Сейчас только заголовки, подтверждённых наблюдений нет. Одна строка — одно предложение одного продавца в момент проверки.
- `catalog-preview.json` — первоначальный снимок демо-матрицы, не источник интерфейса. Приложение при загрузке читает `catalog-matrix.csv` напрямую. После изменения CSV обновите страницу: модели, цены, цвета и размеры обновятся из матрицы. В этой версии интерфейс отображает только строки `record_status=demo`; подтверждённые записи будут подключены при переходе магазина в рабочий режим.
- `feed-demo.xml` — демонстрационный YML, 144 предложения с тестовыми ценами и адресами `.invalid`, без реальных фотографий. Не загружать в рекламные системы. `available=false` в этом примере — техническая заглушка, а не результат проверки отсутствия товара.
- `generate-feed.mjs` — локальный генератор YML из CSV, без установки пакетов.
- `feed.config.json` — настройки магазина; компания и публичный URL пока не заполнены.
- `feed-validation.json` — результат последней проверки готовности боевого фида.

## Что заполнить

В матрице подтвердите модель, цвет, размер, описание и категорию. Укажите собственную цену `price_rub`, собственный остаток `stock_qty`, источник `own_data_source`, дату проверки `verified_at` в ISO 8601 с часовым поясом, публичные HTTPS URL карточки конкретного варианта и фотографии, права на фотографию `image_rights_confirmed=true`. Не подставляйте остатки и цены конкурентов в эти поля.

Пустой остаток означает неизвестность. Ноль означает подтверждённое отсутствие. `availability=in_stock` требует положительного остатка, `out_of_stock` — нулевого. Для включения предложения нужны `record_status=verified` и `publish=true`. В настройках магазина укажите компанию и публичный URL. Свежесть данных по умолчанию — 24 часа.

## Сборка

В папке `data` выполните:

```text
node generate-feed.mjs --demo
node generate-feed.mjs
```

Первая команда обновляет только демонстрационный XML. Вторая проверяет матрицу и настройки, записывает отчёт проверки и при отсутствии ошибок создаёт `feed-production.xml`. При ошибках боевой файл не создаётся и существующий боевой файл не обновляется — перед использованием всегда проверяйте отчёт и дату сборки. Генератор не проверяет доступность URL по сети, принадлежность данных магазину и соответствие фактических остатков введённым данным.

## Статус интеграции

Подготовлен общий YML с группировкой вариантов по модели, ценами в RUB, категориями, цветом и размером. Конкретная площадка ещё не выбрана. Проверка XML выполнена локально, но актуальные требования Яндекс Директа/Маркета через веб-документацию подтвердить не удалось. Перед загрузкой потребуется адаптация и проверка в валидаторе выбранной площадки. Фид не опубликован, публичной ссылки на него пока нет.
