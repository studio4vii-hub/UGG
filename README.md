# UGG — интернет-магазин и Telegram Mini App

Каталог обуви с фотографиями, поиском, фильтрами, избранным и корзиной. Адаптивный интерфейс для браузера и Telegram Mini App.

## Запуск локально

Требуется Node.js 22 или новее. Установка зависимостей не нужна.

```sh
node server.mjs
```

Откройте адрес, указанный сервером.

## Публикация

Загрузите содержимое этой папки в корень репозитория `UGG`, ветка `main`. Не загружайте внешнюю папку `UGG-github` как вложенную папку.

В настройках репозитория откройте **Settings → Pages → Source → GitHub Actions**. Workflow `.github/workflows/pages.yml` собирает папку `public/` и публикует её. Для повторного запуска используйте Actions → Publish GitHub Pages → Run workflow.

## Telegram

Приложение поддерживает Telegram Web Apps SDK, безопасные отступы и кнопку «Назад». После публикации укажите HTTPS-адрес сайта в настройках бота через BotFather. Подробности — в TELEGRAM-GITHUB-SETUP.md.

## Каталог и состояние

- `data/catalog-matrix.csv` — товарная матрица.
- `data/photo-sources.*` и `data/editorial-sources.json` — источники изображений.
- `data/generate-feed.mjs` — подготовка товарного фида с проверкой данных.
- Корзина, избранное и черновики заявок сохраняются на устройстве пользователя.

Отправка заказов менеджеру, серверная авторизация и приём платежей пока не подключены. Цены и наличие в матрице требуют проверки перед коммерческим запуском. Демонстрационный фид не предназначен для загрузки в рекламные системы. Перед использованием сторонних фотографий и товарных знаков необходимо подтвердить права. Лицензия на сторонние материалы этим репозиторием не предоставляется.

Не добавляйте токены бота, пароли или персональные данные в исходники. Секреты сервера должны храниться отдельно от публичного сайта.
